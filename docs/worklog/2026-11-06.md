# 工作记录：域名与网站、本地工作台访问

## 需求与边界

将原“网站管理”调整为“域名与网站”，参照深色服务控制台组织“域名管理 / 网站部署 / SSL 证书”。访问地址直接连接既有 AI 智作台工作台，支持同一局域网中的设备和不同浏览器使用同一服务器数据。按最终确定的本地部署方式实现，不要求新增公网账户或购买域名。

移除页面中的 AI 建站、文件/代码编辑、文字编辑和静态网站导入控件。历史网站草稿仍保留，当前运行模式对旧编辑接口返回已停用提示，不清空数据库。

## 实现

- 网关固定代理本机工作台的页面和业务接口，保留登录、模型设置、对话、工作空间读取与乐观锁保存。管理端继续只监听回环地址，网关不转发管理、内部模型和服务器文件路径。
- LAN HTTP 会话保留 HttpOnly/SameSite 属性，避免错误添加 Secure 导致登录失效；受控 HTTPS 来源可使用 Secure。请求保留实际 Host/Origin，验证跨站写入，过滤管理 Cookie、Authorization 和非必要转发头。
- 网关仅接受本机和实际物理网卡所属私有子网，Host 精确匹配已检测地址或允许绑定。上游状态异常、离线、超时和无效接口返回真实错误，不降级为静态演示。
- 新增物理网络发现，排除 VPN、Docker、WSL、回环、链路本地及伪 IP；定期刷新地址。当前地址是否 DHCP 如实展示，不改变现有 IP 分配或网络类别。
- 局域网开关与修订持久存入新增表，默认关闭；工作台真实实例未初始化访问密码、没有 LAN 地址或网关不可用时拒绝启用。公网配置仅严格布尔 true 生效，本地模式不恢复旧公网通道。
- 域名表支持登记、启停、默认、检测和移除，保存不代表已经绑定。检测使用实际 DNS、有效 TLS 与本机工作台 serverId 比对；有界 HTTPS 请求固定状态路径、校验真实公网 IP 并绑定目标地址，处理 VPN 假 DNS。检测不能覆盖期间的新修改。证书缺失时如实显示，不生成虚构状态。
- 深色界面仅作用于此页，其他管理页面保持原主题。主入口、表格、部署开关、证书页和详情全部使用实际接口数据，兼容窄屏。
- Windows 管理脚本只管理独立命名规则，限制配置中的 Node 程序、网关端口和 LocalSubnet，不停用防火墙，不开放管理端口。脚本需要真实管理员授权；运行前通过语法和参数检查。网络和防火墙只读状态可以分别报告未知或缺失。

- Windows 更新和启动器 Python 20 项、管理控制与安装器 Python 15 项通过。启动器集成验证保留会话、等待任务、切换版本与失败恢复。
- 源码边界、差异格式、PowerShell AST 语法和静态构建检查通过。
- 真实只读网络探测识别物理 Wi-Fi，排除 VPN/虚拟地址；当前防火墙缺少网关规则时正确报告缺失。
- 浏览器验证新页面、三个页签、局域网启用操作、域名配置提示、页面主题隔离与手机宽度无横向溢出。Chrome 和内置浏览器均从隔离网关打开既有工作台的服务器登录页；未读取或更改原工作台密码，未为了验收调用收费模型。

## 发布与限制

沿用协作分支与现有 PR。正式部署等待精确提交的 push CI 通过，继续使用升级前数据库备份和失败代码回退流程。远端 CI、正式切换及防火墙实际授权结果在 PR 补充，不提前宣称跨物理设备已验收。

本地地址属于局域网 HTTP 访问，设备需要在同一网络并使用工作台密码登录。DHCP 地址可能变化；长期固定需由路由器保留地址。公网域名需要拥有其 DNS 管理权限，不能注册他人域名下未获授权的子域名。接口不将待配置 DNS 或未部署证书描述为可用服务。

公开仓库不保存本机地址、实际机器名、运行配置、数据库、密钥、原始日志、截图或聊天全文。

# 2026-11-04 开发记录（Asia/Shanghai）

## 需求与范围

统一本地与云端的实际项目源代码，以 GitHub 为版本来源，让通过验收的提交同步到 Docker 前后端和独立 Windows 智作台服务端。只同步公开项目代码及开发摘要，不同步聊天全文、附件、账号、密钥或运行数据库。

## 实现

- 将此前仅在本机运行的 `admin/` 管理服务、工作台真实模型接入和 Token 统计纳入仓库。保留既有云端 Git 历史，不复制本机配置或状态。
- 以 `codex/gpt-docker-github` 为协作与本机跟随分支，更新 AGENTS 与同步文档，要求先检查/拉取，再开发、验证和提交推送，不自动合并主分支。
- 增加 `ops/windows/` 发布清单与更新源码。更新器接受精确 SHA 的成功 push CI，构建原生仓库源码；旧模型补丁仅用于旧版本回退。
- 管理代码与稳定数据目录分离，启动器跟随已接受提交切换服务。等待管理任务与模型调用完成后切换，保留登录、配置、DPAPI 数据和统计；新服务启动失败时恢复旧代码。
- 前后端与管理服务均通过健康检查才确认版本；更新前备份两个数据库，失败提交隔离，回退不覆盖业务数据。修复 Windows 回退时间戳及模型版镜像离线备份检查。
- 管理页增加仓库、分支、前后端与独立服务端提交和版本一致性信息。
- 增加源码边界检查与 Windows CI；延续 Linux 和真实 Docker HTTP CI。

远端 CI 和正式版本切换须在提交推送后执行；最终验收结果记录在对应 PR。持续发布仍要求本机开机、用户登录、Docker 引擎运行及 GitHub 可访问。聊天窗口中的未提交片段不会被自动发布。

## GitHub 与远程 MCP 插件连接

- 需求：移除插件页三个内置工具卡片，提供可实际连接和使用的外部服务；优先 GitHub。
- 实现：GitHub 官方 MCP 与自定义远程 Streamable HTTP（无授权/Bearer），初始化及分页发现实际工具后显示连接状态；提供工具选择、手动 JSON 调用、启停、刷新、断开和调用记录。桌面及手机界面保留现有导航。
- 对话：选择最多 4 个服务，现有模型生成具体工具计划，页面展示服务、名称与参数供确认。服务端保留原计划，确认后调用真实 MCP 并以返回结果继续对话；取消不调用工具或追加模型步骤。支持 OpenAI 兼容、Anthropic、Gemini 原生工具协议。
- 数据：连接、调用状态和私有对话操作按账号持久保存；凭据使用 AES-256-GCM 加密及独立 plugins.key。原工作空间及旧备份保持兼容；不将凭据或私有执行记录加入工作空间 JSON 导出。连接异常禁止新操作，超时/重启的未知结果不自动重放。

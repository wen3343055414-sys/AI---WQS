# 2026-11-05 开发记录（Asia/Shanghai）

## 需求与设计

将单个模型接口设置升级为多个 AI 服务商和多个模型的统一管理，连接后自动同步工作台，保留既有配置与实际 Token 统计。

结合连接表单、模型清单、密钥及限额的界面参考，查阅 Cherry Studio、Dify、Open WebUI 和国内外服务商官方文档，采用“服务商连接 / 模型列表 / 用量与限额”三个视图。保留现有浅色管理风格，提供搜索、地区筛选、连接状态、模型启停、显示名称及默认模型。调研链接与边界见 [多模型管理说明](../multi-model-settings.md)。

## 实现

- 增加 14 个可编辑模板，覆盖国内、海外、本机和自定义连接；使用模型目录或手动 ID，不硬编码可能过期的模型名称、价格或额度。
- 增加 OpenAI 兼容、Anthropic Messages 和 Gemini generateContent 文本对话适配，按连接使用对应认证、请求与用量格式。MiniMax 使用当前中国站地址及支持的生成长度参数。
- 每个连接独立保存加密密钥，空白保留，替换和清除明确操作；变更来源或协议需重新提供凭据。首次迁移直接复制旧密文，不要求重新输入已有密钥。
- 模型目录新发现项默认停用，保留手动名称和启用选择；支持手动添加、全局筛选、启停、默认模型和移除。停用默认模型后明确暂停，不自动切换服务商。
- 工作台输入框支持按服务商选择模型，默认跟随服务端；请求保存所选模型并继续使用原有去重和回复恢复机制，不把失败请求自动发送给另一个服务商。
- 用量表增加连接及模型标识，保留原合计；按北京时间统计月限额，在发送上游前拦截已达到限额的新请求。未知用量不冒充零，进行中请求可能超额，不计算推测账单或余额。
- 新表与旧接口兼容快照并存，代码回退不删除多模型表或用量。旧代码不理解的原生默认模型暂停对话；多模型配置在当前版本管理。
- 修复界面验收发现的保存后工具栏未恢复操作问题，以及模型保存后重新加载失败时的误报成功。

## 网站管理与公网发布（管理端 1.4）

需求：在本地服务端增加可自由编辑、实际发布并通过公网网址访问的前端网站板块，复用既有管理登录、模型配置和自动更新链。

- 新增网站列表、品牌/个人/空白起始页面、网站设置、文字与链接编辑、HTML/CSS/JavaScript 文件编辑、图片和字体导入、项目导入导出、手机和桌面预览、发布、下架及删除。
- 草稿、发布快照和修订存入稳定管理 SQLite 数据库。保存不改变访客内容；发布原子替换快照；修改网址前保留上一发布路径。过期修订和模型生成期间的并发修改返回冲突，原数据保留。升级与代码回退不清除新表。
- 访客使用独立本机监听端口，默认 3200；不提供管理接口、服务器文件或目录列表。草稿预览使用 15 分钟随机令牌及严格沙盒；已发布页面支持模块、同源资源和 localStorage，多个网站路径共享访客来源。公开资源只允许匿名 CORS。
- AI 生成复用已启用模型、密钥保管、请求去重和真实 Token 记录。输出先验证再保存草稿；截断、格式错误或修订冲突时不覆盖内容，不自动发布。没有真实配置时明确禁用生成，不使用模拟回复。
- 新增可启停的 Cloudflare Quick Tunnel，固定只转发网站访客端口。官方安装器校验来源、版本、大小和 SHA256；独立配置及受限子进程环境避免继承其他隧道路由。仅在实际注册连接后提供公网 URL，断线时撤销可用状态，启用意图持久保存。固定域名可配置独立正式入口，但配置本身不代表连接已验证。
- Windows 启动器停止已拥有的 Node 子进程树，避免版本切换留下通道进程；常规退出清理通道。统一请求体按字节汇总并严格解析 UTF-8，避免多字节内容跨网络分块损坏。
- 官方通道安装说明及限制见 [网站公网通道](../../admin/docs/website-tunnel.md)。临时域名会随重建变化，没有持续运行保证；本机需开机联网。网站板块提供静态前端，业务数据库、支付及邮件需要真实后端。

- 验证覆盖 `npm test`、源码检查、静态构建、Linux 和管理端 Python 测试，以及 Chromium 中的登录、历史对话、插件确认、群聊和协作流程。多模型联调使用本地模拟网关，覆盖并发、定向回复、失败重试、刷新恢复、320 px 和 390 px 布局。

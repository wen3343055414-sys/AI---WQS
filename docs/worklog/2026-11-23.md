## AI 对话改版

- 重做「AI 对话」页面，桌面采用会话列表、消息区和成员三栏。窄屏用抽屉切换会话与成员，支持会话搜索、键盘选择 @ 成员和深色主题。
- 单聊沿用现有模型与 MCP 确认流程。群聊从服务端已启用的模型中选择成员，各模型独立回复。协作为成员分配角色，再由指定模型读取各成员的结论并汇总。
- 成员、分工、汇总模型和步骤进度跟随会话保存。执行复用现有模型网关的并发限制和请求缓存，支持恢复中断的请求和重试单个失败成员。旧会话与备份继续可读。
- 验证覆盖 `npm test`、源码检查、静态构建、Linux 和管理端 Python 测试，以及 Chromium 中的登录、历史对话、插件确认、群聊和协作流程。多模型联调使用本地模拟网关，覆盖并发、定向回复、失败重试、刷新恢复、320 px 和 390 px 布局。

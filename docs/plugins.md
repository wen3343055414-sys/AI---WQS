# 连接插件并在对话中使用

插件页面提供真实远程 MCP 连接。先验证服务并读取实际工具，再选择用于对话的操作；模型提出工具请求时展示服务名称、工具和参数，确认后才执行。GitHub 连接使用官方远程 MCP，也可接入其他兼容服务。

## GitHub

1. 打开 **插件 → 连接 GitHub**。
2. 在 GitHub 令牌设置创建个人访问令牌，限定需要协作的仓库与权限。读取仓库通常需要仓库 Metadata/Contents 读取权限；处理 Issue、Pull Request 或修改文件需对应写权限。组织策略、SSO 和服务端权限也可能限制工具。遵循 GitHub 官方 MCP 文档，按实际需要授权。
3. 将令牌填写在智作台的密码输入框，点击 **连接并验证**。凭据在后端加密保存，不写入浏览器存储、页面列表或工作空间备份。
4. 连接成功后查看服务实际返回的工具。可直接填写 JSON 执行，也可选择“在对话中使用”，让已配置的模型提出工具请求。

官方地址固定为 https://api.githubcopilot.com/mcp/ 。当前默认请求 context、repos、issues、pull_requests 工具集；可用工具及远端执行结果以服务实际返回和账号权限为准。

智作台采用独立的个人访问令牌授权。ChatGPT 中已连接的 GitHub 账号和凭据不会自动转移到本应用。当前未实现 GitHub OAuth 回调；不要将个人令牌发到聊天或提交仓库。

## 其他 MCP 服务

使用 **添加服务** 填写最终 HTTPS MCP 地址，选择无需令牌或 Bearer 令牌授权。支持远程 **Streamable HTTP**（JSON 和 SSE 响应）、MCP 会话与工具分页。服务必须公开工具能力；OAuth 专用服务、旧版独立 SSE transport、stdio 本地命令、资源和提示词协议尚不支持。

每个工作台账号最多 8 个连接，同时可选 4 个用于对话；每个连接最多发现 128 项工具、选择 40 项，单次对话工具定义合计最多 64 项。过大工具集应在服务端缩小。刷新连接会重新发现工具并改变版本；旧确认不会继续执行。

默认仅允许公共 HTTPS 地址，拒绝重定向及内网、回环和元数据地址。自托管管理员确需访问本机 MCP 时，在部署环境设置 **MCP_ALLOWED_LOCAL_ORIGINS** 为逗号分隔的完整 origin（例如 http://127.0.0.1:8765），再重建后端。此管理员设置允许指定 origin 的本地 HTTP，不能由页面用户修改。Docker 内的 127.0.0.1 指容器自身；跨容器服务需使用真实可解析地址和对应 origin。

## 对话与执行结果

- 输入框“插件”选择已连接、已启用且选有工具的服务，继续沿用已有模型配置。更新后的模型桥接支持 OpenAI 兼容、Anthropic 和 Gemini 工具调用；具体模型也必须支持工具能力。
- 模型提出请求后，页面展示不可由浏览器覆盖的服务端操作计划。确认执行后，真实结果送回模型继续回答；后续操作需要再次确认。取消会结束此轮，不执行工具，也不追加模型请求。
- 所选工具定义、工具参数、返回结果和相关对话会发送到现有模型服务；工具参数发送给所连接服务。凭据只用于服务端访问对应 MCP，不作为模型输入。外部返回内容视为数据，不作为授权指令。
- 每轮最多 8 次模型步骤、12 次工具操作，单次确认最多 4 项。模型服务按实际模型请求统计用量；取消不能撤销确认前已产生的模型费用。
- 调用编号和执行状态持久保存。重复确认复用结果，不自动重发外部操作。网络超时、服务重启或连接中断可能显示“结果未确认”；请先到远端核对，再明确准备新调用。远程系统不具备通用的“恰好执行一次”保证。

## 保存、账号与移除

连接、凭据及私有执行记录按工作台账号隔离，存储于后端持久目录。令牌采用 AES-256-GCM 加密，独立密钥为同目录 **plugins.key**（创建权限 0600）。备份恢复插件需同时保留原工作空间 SQLite 数据库和该密钥；JSON 导出仅包含工作空间，不含插件授权和服务端执行日志。密钥损坏时连接显示异常，需恢复原文件或断开后重新授权。

停用会阻止后续执行；断开删除连接及密文凭据，保留调用状态记录。若还需撤销远端令牌，请到 GitHub 或相应服务的授权设置撤销。

旧备份中的内置工具启用字段仍兼容读取，但插件页面已移除工作空间搜索、文本统计和数据导出三个内置卡片。工作台全局搜索与设置中的数据导出继续使用原入口。

## 验收

自动测试通过本地真实 HTTP MCP 服务验证初始化、工具发现、分页、SSE、授权、加密、账号隔离、调用幂等记录和确认后继续对话；本地模型联调服务不调用收费模型接口。浏览器脚本验证实际页面及手机布局。

独立“公共 MCP 实连验收”工作流使用无需个人授权的 DeepWiki 读取公开仓库文档结构，并验证 GitHub 官方 MCP 正确要求授权。它证明协议的外网实连，不代表已授权用户的 GitHub 或验证私有仓库权限。

参考：[GitHub 官方 MCP](https://github.com/github/github-mcp-server)、[MCP Streamable HTTP](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports)。

# 旧版本模型桥接兼容源码

本目录保存原生模型桥接入库之前的兼容补丁，用于追溯和恢复旧安装。适用基础版本为 `f9db8b2d234cb5c9844d49b2b309bbd70d54dbb3`。

当前发布直接使用仓库根目录的 `public/`、`src/` 和 `admin/`；`ops/windows/release.json` 标记原生版本。不要把旧补丁再次应用到原生版本。现有安装目录中的 `integration/` 保持原状，已保留的旧镜像可以继续用于代码回退。

归档包括路径校验和补丁执行器 `prepare.py`、逐段精确匹配的 `patches.json`、Compose 模型桥接配置，以及新增的模型客户端和测试源码。为避免 Node 自动重复发现历史测试，测试源码以 `.fixture` 结尾保存；归档执行器生成旧构建目录时会恢复其原文件名。

需要重建旧构建时，将本目录作为隔离部署目录的 `integration/`，使用独立的旧版发布源码调用 `prepare(root, release, sha)`。执行器只写入 `root/integrated/`，不会改写输入发布目录；匹配失败时拒绝生成构建。不要用此步骤覆盖正在运行的服务，也不要把本机密钥、配置、数据库或日志复制进归档。

正常开发与更新使用 [同步流程](../../../docs/source-sync.md)。
